## ¿Qué es Python?

Python es un **lenguaje de programación de propósito general**, interpretado y de alto nivel. Su lema no oficial es que el código se lee muchas más veces de las que se escribe, así que tiene que ser **fácil de leer**.

```python
print("¡Hola, ULE!")
```

Esa línea ya es un programa completo. En otros lenguajes como Java o C necesitarías bastantes más.

## Un poco de historia

| Año  | Hito |
|------|------|
| 1989 | **Guido van Rossum** empieza a crear Python en las vacaciones de Navidad, en el CWI (Países Bajos). |
| 1991 | Se publica la primera versión (0.9.0). |
| 2000 | Llega **Python 2.0**. |
| 2008 | Sale **Python 3.0**, que no es compatible con Python 2. Desde entonces se usa Python 3. |
| 2020 | Python 2 deja de recibir soporte oficial. |
| Hoy  | Es uno de los lenguajes más usados del mundo según índices como TIOBE o la encuesta de Stack Overflow. |

> **💡 Curiosidad:** el nombre no viene de la serpiente, sino del grupo de humor británico **Monty Python**. Por eso en la documentación oficial aparecen a menudo las palabras `spam` y `eggs`.

## El Zen de Python

Python tiene una "filosofía" escrita. Puedes verla ejecutando:

```python
import this
```

Algunas frases:

- *Bonito es mejor que feo.*
- *Simple es mejor que complejo.*
- *La legibilidad cuenta.*

## ¿Para qué se usa?

- **Ciencia de datos e inteligencia artificial** (NumPy, pandas, PyTorch…)
- **Desarrollo web** (Django, FastAPI, Flask)
- **Automatización** de tareas repetitivas (renombrar archivos, rellenar hojas de cálculo…)
- **Ciencia e ingeniería**: cálculo, simulación, análisis de experimentos
- **Scripting** en servidores y herramientas de sistema
